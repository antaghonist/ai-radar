# ai-radar
Каталог — фильтруйте сервисы по рубрикам и наличию бесплатного тарифа, открывайте пошаговые инструкции и копируйте готовые промпты в один клик.  Конструктор промптов — выбирайте задачу, тон и формат, добавляйте свои детали (или нажимайте «Случайная идея») и получайте готовую команду для нейросети.
